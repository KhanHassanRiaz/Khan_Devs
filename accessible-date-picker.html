Accessible Date Picker: Fill Any Date Field With Confidence

Date of birth fields, flight and hotel bookings, exam application forms: almost every important online form asks for a date, and very often the only way to enter it is a calendar widget that a screen reader cannot read and a keyboard cannot reach. I built Accessible Date Picker to remove that barrier. It is a Chrome extension designed to improve the accessibility of date pickers and calendar interfaces on websites, making online forms and job application processes easier to navigate for keyboard and screen reader users.

The Problem It Solves:

Many websites use calendar widgets that were never designed with assistive technology in mind. Some grids are invisible to the screen reader, some cannot be operated with the arrow keys, and some bury the year selector where it is nearly impossible to find. The result is that a blind or visually impaired user can fill an entire application form, then get stuck at the date of birth field.

Accessible Date Picker solves this by opening its own plain, fully keyboard operable dialog with Day, Month, and Year lists. You choose the date in a dialog your screen reader understands, and the extension writes that date back into the website's own field or calendar. It works with the keyboard alone, it verifies what the page actually contains after every write, and it announces the real field value. It never guesses between an ambiguous day and month, and it makes no network requests and stores no dates.

How to Use Accessible Date Picker

Using the extension takes only a few steps. Just follow them in order, and you will have your date in the form in under a minute.

  • Step 1: Open the website's form and click into the date field with your mouse, or reach it with the Tab key. Make sure the keyboard cursor is sitting inside the field, for example a date of birth box. You can also start from the calendar button that opens the date picker, if the field has one.
  • Step 2: Press Alt+Shift+D. To do this, hold the Alt key and the Shift key together, then press D. Alternatively, click the Accessible Date Picker button in the Chrome toolbar.
  • Step 3: A small dialog opens with three lists: Day, Month, and Year. The Day list is ready first, so simply pick the day you want.
  • Step 4: Now choose the Month and the Year in the same way. The list of days always matches the month and year, so an impossible date such as February the thirtieth can never be picked by mistake.
  • Step 5: Press Enter, or choose the Apply button.

The extension then announces the result. For example, it says "Date set: 10/06/2026." and includes the exact text now in the field. If a website refuses the date, the extension tells you that instead of claiming success.

If the date fails to enter, or you face any error, press the Copy diagnostic report button in the dialog. That copies a plain-text report of what the extension tried. Then send that output to the developer on WhatsApp or by email, and you will get help with the problem.

Changed your mind before applying? Press Escape or choose Cancel, and nothing on the page is touched while your focus goes back where it was. To change the keyboard shortcut, open the extension options and choose Open Chrome keyboard shortcuts, or visit chrome://extensions/shortcuts.

How Dates Are Set

When you apply a date, the extension tries four layers in order and stops at the first one that verifies correctly.

  • Native input. If the field is an input type="date" or input type="month", the extension sets its value directly.
  • Site calendar driver. It looks for an open or openable calendar near the field, reads the visible month and year, changes the controls, clicks the correct day, and checks the field afterwards. It waits for calendar animations to settle, and it has a twenty-second and forty-step budget so it cannot loop forever.
  • Library adapter. It detects jQuery UI datepicker, bootstrap-datepicker, flatpickr, Pikaday, and Zebra DatePicker, then calls the library's own public API.
  • Direct write. If the field's format can be proven from its current value, placeholder, a format attribute, accessible text, library configuration, or another date field on the page, the extension writes a formatted value and dispatches the usual input and change events.

After every layer the extension reads the field again. If the value does not match the requested date, it tries the next layer. The final check happens after focus returns to the field, so a late site script cannot silently replace the date.

Key Features

  • Keyboard-first dialog: Day, Month, and Year lists that any screen reader can use, with a focus trap and visible focus outlines.
  • Verified writes: after every attempt the extension reads the field back and announces the real result, never a claim that was not checked.
  • Smart calendar control: it can drive the site's own calendar, including calendars built with jQuery UI, bootstrap-datepicker, flatpickr, Pikaday, and Zebra DatePicker.
  • Dependent field support: age fields and other values calculated from the date update, because the site's own callbacks run.
  • Ambiguity protection: it refuses to write when the day and month order cannot be proven, instead of guessing.
  • Learned formats: after a verified success it may remember the date pattern for that site, storing only the pattern and never the date itself.
  • Diagnostic report: a Copy diagnostic report button produces a plain-text, sanitized report of the field, the calendar, and every step tried, to help when a site refuses a date. It is only copied when you ask, and it is never sent anywhere.
  • Accessible presentation: the dialog supports dark mode, forced-colors mode, and reduced motion, and announcements use separate polite and assertive live regions.
  • Adjustable options: choose the earliest year from 1900 to 2100, the number of future years from 0 to 200, and forget learned formats at any time.
  • Private by design: no network requests, no remote code, no analytics, no telemetry, and no stored dates.

How to Install

You only install the extension once, and it takes about two minutes. Follow these steps in order and you cannot go wrong.

  • Step 1: Click the Download Accessible Date Picker button below. The latest zip file will be downloaded to your computer.
  • Step 2: Find the downloaded zip file, right-click it, and choose Extract All. Remember the folder where you extracted it, for example your Downloads folder.
  • Step 3: Now open Google Chrome and go to the extension management page. Type chrome://extensions in the address bar and press Enter. If you prefer the menus, press Alt to open the Chrome menu, then find Extensions and choose Manage Extensions. Both ways land on the same page.
  • Step 4: On that page, find the Developer mode switch and make sure it is turned on. It is usually in the top right corner.
  • Step 5: Once Developer mode is on, new buttons appear. Click the Load unpacked button.
  • Step 6: In the folder picker, select the folder you extracted in Step 2 and click Select Folder.
  • Step 7: That is it. The extension is installed and ready to use.

For quick access, click the puzzle piece icon in the Chrome toolbar and pin Accessible Date Picker, so its button is always one click away.

Two small notes: Chrome 102 or newer is required. Unpacked extensions are not updated automatically, so when a new release appears, download and unzip it and load the new folder the same way. Chrome also shows a standard developer-mode warning for unpacked extensions, which is expected and safe.

Privacy and Permissions

The extension uses the activeTab permission for temporary access to the page where you invoked it, the scripting permission to inject the content script on demand, and the storage permission for local settings and learned format patterns only. No date value is ever written to extension storage. The production manifest requests no host permissions at all, and the diagnostic report is copied to the clipboard only when you press its button.
