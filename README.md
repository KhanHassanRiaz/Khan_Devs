# KhanDevs Website

Static website for KhanDevs, hosted with GitHub Pages.

- **Live site:** https://khandev.me
- **Custom domain:** `khandev.me` (see `CNAME`; `www.khandev.me` also resolves to the site)
- **Branch:** `main` (repo root is published directly, no build step)

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Home page |
| `products.html` | All products |
| `proquiz-simulator.html` | ProQuiz Simulator |
| `protyping-assistant.html` | ProTyping Assistant |
| `pro-typing-master.html` | Pro Typing Master |
| `synonyms-and-antonyms.html` | Synonyms and Antonyms NVDA add-on |
| `contact.html` | Contact |

Shared assets are `style.css`, `script.js`, the logo/image files, and the favicons.
